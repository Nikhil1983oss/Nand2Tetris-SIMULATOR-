## Overview
A complete 16-bit Hack computer implementation, two-pass Python assembler, assembly graphics routine, and interactive web simulator (`index.html`). Holding any keyboard key draws a solid black box on the Hack screen; releasing the key clears it.

## Personalized Specifications ($K = 49$)
* **Start Row:** `49` (`SCREEN + 32 * 49 = RAM[17952]`)
* **Box Size:** `32 × 20` pixels (`2` words wide × `20` rows tall, rows `49..68`)
* **Assembler Extra ($K \bmod 3 = 1$):** Reports malformed lines as `Line <n>: invalid instruction` without crashing and exports `symbols.txt`.

## Files Included
* `CPU.hdl`, `Memory.hdl`, `Computer.hdl` — Hack CPU, memory map (`RAM16K` + `Screen` + `KBD`), and top-level computer chips.
* `assembler.py` — Two-pass Hack assembler (`python assembler.py Box.asm`).
* `Box.asm` & `Box.hack` — Hack assembly source and assembled 16-bit binary.
* `symbols.txt` — Resolved symbol table generated by `assembler.py`.
* `index.html` — Standalone MARK-49 interactive web simulator.

## Quick Run
1. **Web Simulator:** Open `index.html` in any browser and hold **HOLD KEY TO DRAW BOX** (or any physical key).
2. **Assembler:** Run `python assembler.py Box.asm` in your terminal to generate `Box.hack` and `symbols.txt`.
3. **HDL Verification:** Load `Memory.hdl`, `CPU.hdl`, and `Computer.hdl` in the Nand2Tetris Hardware Simulator and run their `.tst` scripts.
